# 轻译 TransLite

轻量、可自定义的 Firefox 网页翻译扩展。译文**原位显示**，完全继承原网页的字体、颜色与排版，不加底色、不加竖线、不插入额外容器。

- **仓库**：<https://github.com/PatenX-AI/translite>
- **版本**：`v1.4.0`
- **许可证**：[MPL-2.0](LICENSE)
- **隐私政策**：[PRIVACY-POLICY.md](PRIVACY-POLICY.md)

---

## 为什么用它

- **接入任意大模型**：填一个 OpenAI 兼容的接入点和 Key，就能用云端 API、本地 Ollama / vLLM 或自建服务；本地端点可留空 Key。支持多模型接力、连败自动降级、恢复后回切。不填任何 Key 也能用内置的免密钥微软翻译，另有百度翻译可选。
- **一次请求翻译多段**：相邻段落按「最多 50 段 / 1000 字符，先到为准」合并成一批调用，大幅减少 API 请求次数，降低触发限频的概率；同文去重与译文缓存进一步避免重复请求。并发数、调用间隔、整批重试次数都可调。
- **提前翻译，滚动即读**：默认只翻译可视区域，并可提前 1~10 屏预取；滚到下面时译文已经就绪，不必边滚边等。需要时也可切换为完整页面。
- **正则 + XPath 级自定义**：按站点定义翻译行为规则（跳过 / 双语不换行 / 仅译文），可命名、可限多站点、可用正则模板一键填写；正则按完整段落匹配，段内夹着正常语句也不会误跳过。提示词模板同样可按站点自动套用。
- **读得舒服**：译文零装饰、完全继承原网页样式；仅译文 / 双语对照 / 原文随时切换；双击或按住触发键做「指译」预览。
- **收得住**：工具栏「全局总开关」关闭后不向页面注入任何代码，按钮、快捷键、自动翻译、指译全部不响应。

## 功能一览

| 能力 | 说明 |
|---|---|
| 翻译引擎 | 任意 OpenAI 兼容接口（自填接入点 / Key，多模型接力与降级）、微软免密钥（默认）、百度（APPID + 密钥） |
| 批量与调度 | 段落合并（50 段 / 1000 字符先到为准）、并发 2、可调间隔、整批重试、译文缓存与同文去重 |
| 翻译范围 | 可视区域（提前 1~10 屏）/ 完整页面；常规翻译同样遵守 |
| 显示与指译 | 仅译文 / 双语对照 / 原文；双击持久切换 + 按住临时预览，共用 7 选 1 触发键 |
| 自动翻译 | 按原始语言匹配的「全部站点」与「自定义站点」两个独立开关，可全部关闭 |
| 手动范围 | 当前页 / 当前域名（同域其它标签页与新页面同步生效） |
| 翻译行为规则 | 名称 + 站点 + XPath / 正则 + skip / inline / trans；内置编号、邮件、网址过滤 |
| 提示词模板 | 内置通用 / 科技文献 / 专利模板，可编辑、命名、复制，按站点自动套用 |
| 配置 | 可选 Firefox Sync、JSON 导出 / 导入 / 重置、缓存清理 |

扩展不收集浏览历史、点击流、搜索词、账号信息，不含统计、广告、崩溃上报或遥测。翻译时只把待翻译段落文本发送到所选引擎。详见[隐私政策](PRIVACY-POLICY.md)。

## 安装

**正式版**：Firefox 扩展中心（AMO）审核通过后安装签名版。

**临时试装**：

1. 从 [Releases](https://github.com/PatenX-AI/translite/releases) 下载 `translite-1.4.0.xpi`；
2. Firefox 打开 `about:debugging#/runtime/this-firefox` → 「Load Temporary Add-on」→ 选择该 XPI；
3. 点工具栏「译」图标打开主控台。

临时安装的扩展在浏览器重启后失效。XPI 是标准 ZIP 包，解压即完整源码，也可直接加载 `extension/manifest.json`。

## 内容

```
extension/                 扩展源码（XPI 内即这些文件）
  manifest.json            MV3 清单
  background.js            唯一中枢：配置 / 缓存 / 引擎 / 状态角标 / 动态注入
  content.js               页面执行器：分段 / 渲染 / 队列 / 指译
  lib/core.js              纯逻辑（可被 Node 直接 require）
  lib/sync-chunks.js       Firefox Sync 分片
  popup/                   工具栏主控台
  icons/                   16 / 32 / 48 / 96 / 128 PNG
dist/translite-1.4.0.xpi    发行版
PRIVACY-POLICY.md           隐私政策
```

源码即交付物：页面内不注入任何 UI，工具栏面板是唯一交互入口。
